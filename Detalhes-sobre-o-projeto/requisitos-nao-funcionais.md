Requisitos Não Funcionais
Os requisitos não funcionais definem características de qualidade, segurança, desempenho e funcionamento do sistema.

RNF01: O sistema deve possuir uma interface responsiva para computadores, tablets e celulares.

RNF02: As páginas do sistema devem carregar rapidamente, evitando longos tempos de espera.

RNF03: O sistema deve utilizar HTTPS para proteger a comunicação entre usuário e servidor.

RNF04: Os dados pessoais dos usuários devem ser armazenados de forma segura.

RNF05: O sistema deve proteger os dados utilizados durante os pagamentos.

RNF06: O sistema deve possuir uma interface simples e intuitiva para facilitar sua utilização.

RNF07: O sistema deve permitir uma navegação adequada em diferentes tamanhos de tela.

RNF08: O sistema deve realizar backups periódicos do banco de dados.

RNF09: O sistema deve possuir disponibilidade adequada para permitir o acesso dos usuários durante todo o dia.

RNF10: O código-fonte do sistema deve ser versionado utilizando Git.

RNF11: O sistema deve possuir uma estrutura que permita futuras atualizações e inclusão de novos produtos e funcionalidades.

RNF12: O sistema deve apresentar mensagens de erro claras quando ocorrer algum problema durante a utilização.
