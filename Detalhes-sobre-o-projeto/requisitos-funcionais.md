Requisitos Funcionais
Os requisitos funcionais descrevem as funcionalidades que o sistema deve oferecer aos seus usuários.

RF01: O sistema deve permitir o cadastro de clientes com nome, CPF, e-mail, telefone e endereço.

RF02: O sistema deve permitir que o usuário faça login utilizando e-mail e senha.

RF03: O sistema deve permitir que o usuário altere seus dados cadastrais e endereços.

RF04: O sistema deve disponibilizar a opção de recuperação de senha por e-mail.

RF05: O sistema deve permitir a navegação por categorias de produtos, como ferramentas, sementes, rações, medicamentos veterinários, equipamentos e acessórios.

RF06: O sistema deve permitir a pesquisa de produtos pelo nome.

RF07: O sistema deve permitir filtrar produtos por categoria, marca, preço e disponibilidade em estoque.

RF08: O sistema deve exibir informações detalhadas dos produtos, incluindo nome, descrição, preço, marca, quantidade e imagens.

RF09: O sistema deve informar a disponibilidade dos produtos em estoque.

RF10: O sistema deve permitir adicionar produtos ao carrinho de compras.

RF11: O sistema deve permitir alterar a quantidade ou remover produtos do carrinho.

RF12: O sistema deve calcular automaticamente o subtotal e o valor total da compra.

RF13: O sistema deve permitir calcular o valor do frete a partir do CEP informado pelo cliente.

RF14: O sistema deve permitir ao cliente escolher entre as formas de entrega disponíveis.

RF15: O sistema deve permitir finalizar pedidos informando o endereço de entrega e a forma de pagamento.

RF16: O sistema deve disponibilizar diferentes formas de pagamento, como PIX, cartão de crédito e boleto bancário.

RF17: O sistema deve apresentar a confirmação do pedido após a realização da compra.

RF18: O sistema deve permitir que o cliente consulte o histórico de seus pedidos.

RF19: O sistema deve permitir que o cliente acompanhe o status e o rastreamento de seu pedido.

RF20: O sistema deve enviar notificações ao cliente sobre alterações no status do pedido.

RF21: O sistema deve permitir que administradores cadastrem, editem e removam produtos.

RF22: O sistema deve permitir que administradores controlem a quantidade de produtos em estoque.

RF23: O sistema deve permitir que administradores visualizem os pedidos realizados.

RF24: O sistema deve permitir a geração de relatórios de vendas e estoque.
